## Asset Creation Guidelines

### Style
- Realistic, gritty, post-apocalyptic aesthetic
- Dark color palette: charcoal, muted grays, desaturated blues, dirty browns
- Limited red accents for blood/danger
- 2D sprites with normal maps for lighting

### Technical Requirements
- Sprites: Power of 2 dimensions (64, 128, 256, 512)
- Animations: SpriteFrames format
- TileMaps: 16x16 or 32x32 tiles
- Audio: OGG format, 44.1kHz
- Normal maps: Same dimensions as diffuse

### Licensing
- All assets must be original, CC0, or properly licensed
